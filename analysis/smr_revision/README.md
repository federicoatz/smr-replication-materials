# SMR working revision

Run from the project root:

```sh
Rscript analysis/smr_revision/simulation.R
```

The simulation requires `pwr`, uses seed 20260916, and runs 100 repetitions of eight settings: true correlation .10/.30, median original sample size 100/500, and presence/absence of significance selection. Each repetition starts with 200 claims. Original correlations are generated by the approximate Fisher-z sampling distribution. Original sample sizes have log standard deviation .70 and a minimum of 10. Claims whose safeguard bound is undefined are excluded; significance selection additionally retains only |t| > 1.96. Targets use the same pwr.r.test numerical correlation-power implementation, alpha .05, power .80, and safeguard confidence .80 as the manuscript.

The four generating rules are the point-estimate target, safeguard target, twice the original sample, and safeguard target capped at 500. All use common multiplicative implementation noise with log standard deviation .15 within each repetition. In the capped rule the cap is applied after noise; realized samples never exceed 500. Samples are rounded and bounded below at 4.

`simulation_diagnostics.csv` records retention and exclusions where the numerical solver fails to bracket a target within its supported range. `simulation_draws.csv` records coefficients, conditioned-model condition numbers, attainment, and median realized-to-safeguard ratios. `simulation_summary.csv` reports setting-specific means and Monte Carlo standard errors for the coefficients. Script assertions check recovery of exact 0/1 slopes in the two target-driven rules without implementation noise and paired slope differences with noise.

This is a controlled evaluation of the diagnostic, not a reconstruction of SCORE planning decisions, a calibrated selection model, a comparison of all defensible planning methods, or validation of the common correlation benchmark for heterogeneous designs. No replication outcomes are simulated. No visual or typesetting checks were performed.
